DEPRECATED EXAMPLE NAME
=======================

This historical filename is retained only so source-tree overlay patches can
replace older documentation without requiring a delete operation.

DAI Engine no longer contains project-specific directional-combat rules.
Physical input gestures, action bindings, directional thresholds, and
first-person poses are defined by data/resource JSON in:

  data/<namespace>/input_profiles/*.json
  assets/<namespace>/input_profiles/*.json

See input_profile.json in this directory for the generic format. The runtime
contains no project item ids, action ids, pose values, or directional-combat
policy.
