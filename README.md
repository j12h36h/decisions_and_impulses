# Decisions & Impulses (DAI)

Official repository for the Decisions & Impulses (DAI) Project, consisting of the DAI Engine, official Data Packs, and official Resource Packs.

## Purpose

The purpose of this project is to bring the **DAI Engine** to Minecraft: Java Edition.

### DAI Engine (Mod)

The DAI Engine provides the systems and functionality that execute gameplay behavior.

- Fully integrates with nearly all vanilla Minecraft features.
- Executes impulses, decisions, pathfinding, and interface behavior.
- Reads definitions provided by DAI-compatible Data Packs.

### Data Packs

Data Packs define content and compatibility.

- Describe impulses and decisions.
- Add compatibility with vanilla Minecraft and other mods.
- Extend the DAI Engine without modifying its source code.

### Resource Packs

Resource Packs define presentation.

- Customize user interfaces.
- Replace or extend textures, sounds, and other visual assets.
- Provide alternative themes while remaining compatible with the DAI Engine.

## Design Philosophy

> **The Mod does.**
>
> **The Data Pack defines.**
>
> **The Resource Pack presents.**
